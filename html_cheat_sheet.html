HTML Cheat Sheet

Die Überschriften

Folgende Tags werden verwendet, um Überschriften zu markieren:

h1 ... Ist die Haupt-Überschrift
h2 ... Ist die 2. wichtigste Überschrift
h3 ... Ist die 3. wichtigste Überschrift
h4 ... Ist die 4. wichtigste Überschrift
h5 ... Ist die 5. wichtigste Überschrift
h6 ... Ist die letzte mögliche Stufe von Überschrift

Absatz & Zeilenumbruch

Folgender Tag wird verwendet, um ...
< p > ... "p" steht für "paragraph"
< br > ... "br" steht für "line break". ACHTUNG: Dieser Tag hat keinen closing Tag. (< /... >)

Textformatierungen

< strong > ... markiert den Text als fett
< em > ... markiert den Text als kursiv
< i > ... markiert den Text als italic

Die HTML Grundstruktur

Erste Ebene - Root Ebene

Folgende Tags werden verwendet:

-< DOCTYPE html > ...Erste Zeile. Es hat keinen closing Tag
-< html > ...Der HTML Tag. Er beinhaltet alle weiteren Tags. Er hat einen closing Tag

Innerhalb vom HTML Tag

Folgende 2 Tags verwendet
-< head >... Hier sind Inhalte, die für den Browser wichtig sind. (Titel im Tab, Titel...)
-< body >... Hier sind alle Inhalte, die die User sehen.

Innerhalb vom HEAD Tag

-< title >... Dieser Tag ist notwendig. Der Inhalt wird im Browser-Tag angezeigt. Achtung: "title" und NICHT "titel"!!!
-... weitere wichtige Tags folgen!

Innerhalb vom BODY Tag

Hier steht alles, was auf der Website zu sehen ist, also sozusagen alles was oben steht wird hier verwendet, außer die
Root Ebene, der HTML Tag und der HEAD Tag.
